# Yamori

## Register

product

## Users

People who can handle difficult ideas, including mathematics, but need programming context made explicit. They read and plan changes in VS Code or Cursor across multiple script files.

## Product Purpose

Communicate what code does, how and why, through concise pseudocode, a navigable project canvas, and plans discussed with the user's Codex or Claude subscription.

## Brand Personality

Friendly, clear, playful. Pixel gecko samurai identity. Quiet monochrome chrome, restrained animations, terminal-style planning conversation, green additions and yellow changes.

## Anti-references

Cluttered toolbars, hidden primary buttons, nested dialogs, verbose academic pseudocode, repeated before/after blocks, and permanent comment forms.

## Design Principles

- Show the main destinations and actions without opening a menu.
- Keep the canvas and conversation available while exploring a plan.
- Make a change understandable before asking a reader to inspect implementation details.
- Reuse local cached explanations and keep reading separate from paid generation.
- Prefer one concise proposed result over repeated descriptions.

## Accessibility & Inclusion

Use clear text labels, keyboard access and visible focus. Accompany change colors with symbols. Respect editor themes and reduced motion.
